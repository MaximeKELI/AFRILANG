# pkg_metier_demo

Démos des **19 paquets métier** AFRILANG.

```bash
cd examples/apps/pkg_metier_demo
afrilang pkg install
afrilang run src/main.afr           # vague 1
afrilang run src/metier2_demo.afr   # vague 2
afrilang run src/metier3_demo.afr   # vague 3
afrilang run src/storex_demo.afr    # SQLite
```

`afrilang pkg search metier` liste tout le catalogue tagué.
